Methods

Standing rules for everything on this page: a pre-registered dev gate before a run counts; held-out topics and held-out wordings, never reused from estimation; effects reported against a control-referenced z-score rather than an absolute threshold; no experiment built until its readout has been piloted on data already on disk.
